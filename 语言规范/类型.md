# 类型

类型也是值，可以用变量存储。用 `类型()` 获取类型。
可以这样定义类型：

```mymz
#定义 类型 布尔:=字节。
布尔 A:=0。
```

`#`标记代码在编译时执行。和类型有关的操作只能在编译时进行，并且结果必须是**确定的**。

可以用 `类型` 类型的变量作为类型声明其它变量。这个类型必须是确定的。
类型不存储可变性。
## 类型相等
只有**引用**才相等：

```mymz
定义 整数 变量 甲。
#定义 类型 常量 引用 整数类型:=甲 的 类型。
定义 整数类型 变量 乙。//整数
整数类型=整数 //真
#定义 类型 常量 新类型=整数。
新类型=整数 //假
```

这条规则解决了**新类型**的问题：`定义 类型 名称:=已有类型` 得到的是一个**大小与已有类型相同、但不等价**的新类型。
## 大小

用 `的 大小` 获取类型的大小。单位是字节。
```mymz
#定义 整数 常量 整数类型的大小:=整数 的 大小。
```
这也是编译时操作，只能在`#`标记的代码中使用。
## 类型转换
使用`类型()`将值转换为指定类型。这个操作不会对内存进行任何处理，只改变类型。  
使用`转换为`可以将值在字节、整数和浮点数间转换。它会保持数值不变(浮点数转为整数时会丢失小数部分)。
