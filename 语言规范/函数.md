# 函数

函数也是值。
## 函数类型
用`函数[]`表示函数类型。`[]` 中是**参数**和**返回类型**，返回类型不写就是无返回值。
## 函数值
函数值以`函数()`开头。`()`中是参数，后面是返回类型，最后是函数要执行的代码。

```mymz
定义 函数[整数，整数。返回 整数] 常量 加:
=函数(整数 甲，整数 乙)返回 整数{
	返回 甲+乙。
}
```
## 调用
在函数值后加`()`调用函数。`()`中的参数将被传递给函数。
```mymz
定义 整数 常量 一加一的和:=加(1，1)。
```
传入的参数时将使用**值传递**，修改不影响原变量。如果要在函数中修改变量的值，需要使用引用。

变量可以被传给接受常量引用的函数，常量不能传给接受变量引用的函数。
