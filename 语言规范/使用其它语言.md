# 使用其它语言

没有名字可以使用**C 接口**和其它语言相互调用。所有操作都遵循**C ABI**：函数符号不做名字修饰，参数和返回值只使用C的类型。

## 没有名字调用其它语言
用`外部`导入外部值：
```cpp
#include<iostream>
extern "C"{
	void output(int n){
		std::cout<<n;
	}
}
```

```mymz
定义 函数[整数] 常量 输出:=外部 函数[整数] output。
```

`外部` 后面是类型和导出的符号名。  
它是一个值，可以直接使用：
```mymz
外部 函数[整数] output(42)。
```

### 访问外部变量
```cpp
#include<iostream>
extern "C"{
	extern int global_var;
}
```

用`外部`访问外部变量。
```mymz
定义 整数 变量 外部变量的值:=外部 整数 global_var。
定义 整数 变量 引用 全局变量:=外部 整数 global_var。//现在可以直接使用“全局变量”访问global_var
```

## 其它语言调用没有名字

在定义前加`外部`即可导出名称：

```mymz
定义 外部 函数[整数，整数。返回 整数] plus:
=函数(整数 甲，整数 乙){
	返回 甲 + 乙。
}。
定义 外部 整数 变量 sum。
```

```cpp
extern "C"{
	int plus(int,int);
	extern int sum;
}

int main(){
	sum=plus(1,1);
	return 0;
}
```

## 类型限制

定义外部函数或变量时**只能使用 C 的类型**：

| 没有名字类型 | C 类型 |
|-------------|--------|
| `字节` | `unsigned char` |
| `整数` | `int` |
| `浮点数` | `double` |
| `指针` | `*` |
所有C类型可以对应和它大小相等的字节数组。
