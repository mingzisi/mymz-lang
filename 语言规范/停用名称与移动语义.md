# 停用名称与移动语义
## 作用域

所有名称的作用域都是**它所在的代码块**。
在执行到此代码块外时这个名称会被**自动删除**。
没有名字允许声明同名变量，但必须**不在同一作用域中**。如果声明名称相同的变量，之前的同名变量将会**隐藏**，直到新声明的变量离开作用域被删除后才重新可见。

## 停用名称

使用 `停用` 停止使用一个名称。

```mymz
定义 整数 变量 甲。
甲:=0。
定义 整数 变量 引用 甲的引用:=甲。
停用 甲。
定义 浮点数 变量 甲。
甲:=1÷10。//甲是浮点数变量
甲的引用:=1。
```

停用不影响作用域，使用引用仍然可以访问原变量。

## 移动语义

当变量被赋值后值源变量不再被修改时，将会触发移动语义。

```mymz
定义 整数[1000] 变量 很大。
定义 整数[1000] 变量 移动。
移动:=很大。
停用 很大。//可以确定“很大”不会被修改，上面将会使用移动语义
{
	定义 整数[1000] 变量 局部。
	移动:=局部。//也会触发移动
}
```

移动语义也会在函数返回导致临时变量失效时触发。

## 命名空间

命名空间可以隔离名称，可以在不同的命名空间里使用相同的名称。
用 `：` 指定使用哪个命名空间中的名称。

```mymz
定义 命名空间 示例命名空间。
定义 整数 变量 甲。
命名空间 示例命名空间{
	定义 整数 变量 甲:=0，乙。
}
甲:=示例命名空间：甲。 //将外部的甲赋值为内部的甲
使用 命名空间 示例命名空间。//使用整个命名空间
乙:=甲。//这是示例命名空间内的甲
停用 示例命名空间。
甲:=1。//外部的甲
使用 示例命名空间：乙。//使用示例命名空间内的乙
乙:=甲+1。
```

命名空间可以嵌套。
