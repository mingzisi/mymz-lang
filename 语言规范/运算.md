# 运算

| 运算符               | 含义   |
| ----------------- | ---- |
| `:=`              | 赋值   |
| `+ - × ÷ div mod` | 数学运算 |
| `= ≠ ＞ ＜ ≥ ≤`     | 比较   |
| `& \| ~ ^ << >>`  | 位运算  |
## 赋值

`:=` 是赋值，让左边等于右边。  
赋值操作不产生值。

```mymz
定义 整数 变量 甲。
甲:=0。
定义 整数 变量 乙。
定义 整数 变量 丙。
//乙:=丙:=甲。 不能这么做！
```

## 数学运算

`+ - × ÷` 是加、减、乘、除。

`+`和`-`可以对`整数`、`浮点数`和`字节`进行。操作数的类型需要相同。

也可以对指针使用`+`和`-`。左操作数是指针，右操作数是偏移量。

`div`表示整数除法，`mod` 表示取余数，只能对`整数`或`字节`进行。

```mymz
定义 整数 常量 余数:=10 mod 3。 //1
```

## 比较

`= ≠ ＞ ＜ ≥ ≤` 分别是等于、不等于、大于、小于、大于等于、小于等于，结果的类型是`布尔`。

## 一元运算

`-` 也可以作为一元运算符使用：

```mymz
定义 整数 常量 甲的相反数:=-甲。
```

## 运算顺序

在没有名字中所有二元运算**总是从左到右进行**。`a+b×c` 就是 `(a+b)×c`，而不是 `a+(b×c)`。

要改变计算顺序，需要加括号：

```mymz
定义 整数 常量 甲:=1+2×3。//9
定义 整数 常量 乙:=1+(2×3)。//7
```

## 位运算

`& | ~ ^` 分别表示位与、位或、位取反、位异或。操作数可以是任何相同的类型，结果的类型与操作数相同。
`~` 是一元运算符。
`<<` 和 `>>` 表示位左移和位右移。右操作数是移动位数。
