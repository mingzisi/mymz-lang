# 变量

用 `定义` 定义一个变量或常量。

```mymz
定义 整数 变量 甲。
定义 整数 常量 乙:=0。
```

`定义` 后面依次是**类型**、`变量` 或 `常量`、名称，最后用 `。` 结束。

>名称**只能**由 `字`（Unicode 中属于字母或数字的字符，以及下划线 `_`）组成，且不能以数字（0~9）开头。不只是变量，其它名称也是一样的。

- 声明变量时后面可以在名称后面加 `:=` 进行初始化。
- 常量**必须**在声明时初始化。
## 数组

在类型后加 `[元素个数]` 将类型改为**数组**。数组可以同时存储多个类型相同的元素。使用 `名称[索引]` 访问数组中的元素，**索引从0开始**。

```mymz
定义 整数[10] 变量 数组。
数组[0]:=1。
```

# 字面量
直接写在代码里的值被称为**字面量**。
### 数
整数可以直接写，浮点数只能通过[运算](运算.md)得到。

```mymz
定义 整数 常量 零:=0。
定义 浮点数 常量 π:=31416÷10000。
```

### 字符和字符串

字符串是**字符数组**。字符用 `‘’`，字符串用 `“”`。

字符串可以跨行，`“`、`”` 和 `\` 需要转义。

字符串以空字符结尾，所以长度比字数大 1。

字符使用 UTF-32 编码。

```mymz
定义 字符[8] 变量 字符串:=“这是一个字符串”。
```
