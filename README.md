# 没有名字

一个能修改自己的编程语言。
## 它想解决什么
原本只是想做一个中文编程语言并让它的语法接近自然语言，但是发现中文的语法太复杂了，根本没法做……

> 欸？那让语言能**自己修改自己**不就行了吗！

## 自修改
`#` 标记的代码在编译时运行。它可以匹配代码、读取代码、修改代码、报错，甚至可以改变后续代码的解析方式。高级语法都可以由代码自己生成。

`#代码⟦⟧` 可以匹配并修改代码：
```mymz
#代码⟦循环 ⦅代码 循环体⦆ 如果 ⦅布尔 条件⦆⟧：循环{
	定义 词元 常量 循环开始=⦅标识符⦆。
	循环:=⦃
		定义 跳转 ⦄+循环开始+⦃。
		{
			⦅循环体⦆
			如果 ⦅条件⦆ 跳转 ⦄+⦅循环开始⦆+⦃。
		}
	⦄。
}
```

`#词元` 可以改变分词规则：
```mymz
#代码⟦//⟧：注释{
	#词元“\n”：注释结束{返回 注释结束。}
	定义 代码片段 变量 引用 结束位置:=⟦\n⟧。
	注释~结束位置:=⦃⦄。
}
```
